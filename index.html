Heygo · Chatbot Avatar · 设计方案

语音卡片到底要不要头像？
答案是：先去掉，但把位置留好。

这一版把讨论里的两种意见（Edward：「要么去掉，要么真有活人感」；Leon：「支持去掉，等 Heygo 虚拟形象定了再一起加」） 放进同一个界面里对比。结论不是二选一，而是一个头像槽位、三档形态——今天上最克制的那档， 等虚拟形象定稿后换资源即可，不改布局、不返工。

交互 demo · 可点击切换方案与状态 · 配色取自 app_flutter 的 AppPalette

1 · 现在这个图标为什么不成立

它同时踩了两边：既没有「活人感」，也不够克制到能当纯系统元素。

问题

灰剪影 + 声波 = 设备在播报

没有脸、没有情绪、没有名字。用户读到的语义是「系统在念一段话」，不是「有个教练在跟我说」。

Edward：「它不是个【人类会用的头像】，它是个系统标志。」

问题

它占了位置，却没提供信息

卡片里已经有时间戳和文案。这个圆形图标既不区分说话人（全场景只有一个 Chatbot），也不表达状态，是纯装饰。

Leon：「我们目前所有场景都没有这个，慎加。」

约束

虚拟形象还没定

现在临时造一个角色，等 Heygo 官方虚拟形象定稿后大概率要推翻重做，还会在用户心里留下两个「它」。

Leon：「最好等 heygo 虚拟形象定了，再一起加。」

2 · 四个版本，放进真实界面里比

同一张语音实时反馈卡 + 同一段聊天问答。点下面的按钮换聊天状态，看头像在动态场景里的表现。

3 · 推荐方案：A 现在上，B 备着，C 等形象

A 立刻解决 Edward 说的问题，也满足 Leon 的「先别加」；同时组件层留出 avatar 槽位，后面换成 C 是换一个 asset，不动布局。

现在这个版本 · 本周可交付

A｜不放头像

  • 去掉灰色声波图标
  • 左侧 3px 薄荷色竖条区分「这是 Coach 说的」，不是用户内容
  • 加一行说话人标签「Coach · 10:07」，把身份交给文字
  • 卡片宽度多出 44px，长句少折一行
可选过渡 · 需要品牌感时再开

B｜品牌 Mark

  • 薄荷渐变圆 + 一道 carve 弧线（滑行轨迹）
  • 它是品牌，不假装是人，所以不会和未来的虚拟形象打架
  • 随时可开关，一个 CSS token 的事
虚拟形象定稿后 · 换资源即可

C｜Ullr 角色头像

  • 真正的「活人感」：有脸、会眨眼、有情绪
  • 五种状态复用同一套骨架（见下一节）
  • 接入方式和 A/B 完全一致，不改卡片布局

4 · 如果要做角色，它长这样：Ullr

Ullr 是北欧神话里的滑雪之神，也是我们仓库里已经在用的名字。用品牌薄荷 #28F5D2 和柠檬 #B1FE2B， 不用人脸、不用写实，避免和用户自己的头像混淆。点按钮看状态。

待机

卡片里静止时的默认样子。轻微上下浮动 + 每 5 秒眨一次眼，是让它「活着」最便宜的两个动作。

五官只有 3 个元素眼、嘴、腮红 —— 32px 下仍可辨
动效成本纯 CSS / Lottie，无需 3D 资源
和用户头像不冲突非人脸，圆帽 + 雪镜识别度足够
96px 详情页
48px 卡片
32px 聊天
24px 列表

5 · 组件契约：为什么现在去掉，以后不返工

关键不是画什么，是把「头像」做成卡片的一个可选槽位，默认 none。这样 A→B→C 的切换是改一个枚举值。

// coach_message_card.dart
enum CoachAvatar { none, mark, character }

CoachMessageCard(
  avatar: CoachAvatar.none,   // ← 本期
  speaker: 'Coach',
  time: '10:07',
  text: 'The old edge releases late…',
)

// 换形象时只改这一行：
// avatar: CoachAvatar.character
